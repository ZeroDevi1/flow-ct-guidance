## Important negative result: NFE changes do not preserve the method

Read-only matching of the exact4 diagnostic first slices, same measurements,
initialization seed, prior, CG30 and method lambda:

| Method | NFE20 PSNR | NFE50 PSNR | Difference |
|---|---:|---:|---:|
| DC lambda3 |30.6432|27.0788|-3.5644|
| WLS lambda.3 |37.4588|33.5672|-3.8916|

All4 matched patients decreased for both methods. The drop therefore cannot be
attributed solely to expanding the cohort. The sampler repeats fixed-lambda DC
at each time step, so changing NFE changes the guidance sequence/total effect;
it is not a controlled finer-integration-only test. This supports studying
NFE/lambda coupling later, not a proven causal diagnosis or a reason to retune
this completed batch retroactively.

The other16 patients had lower averages too. Anatomy/pathology labels were not
inspected, so no anatomical explanation is established. Selected40 stored
normalized arrays have finite values only, range[-1,1], no out-of-range pixels;
this does not validate original HU calibration or clinical image quality.

## Numerical audit

Original GPU float32/CG12 unit-weight equality gate failed; repeated runs of the
same solver also crossed its1e-5 allclose threshold. The failure was preserved.
Separate GPU float64/CG12 algebraic and float32/CG5 controls passed unchanged
thresholds. Further real-validation CG5/12/30 checks showed substantial WLS
under-solving atCG5 (on4 first slices lambda.3 PSNR29.7073→34.7911→37.4588).
CG30 reduces first-prox normal residuals but is not proof of exact convergence
for every sampling step/image. Float32 GPU nondeterminism remains documented.

Remaining validation patients and final test images are not used in this run.
