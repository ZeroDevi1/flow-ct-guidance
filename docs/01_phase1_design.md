# Phase 1 实验设计 · 01_diffusion_inverse

**时间**：2026-10-20 → 2026-11-15（4 周）
**问题**：稀疏视角（sparse-view）与低剂量（low-dose）CT 重建
**目标**：在同一测试集上对齐 4 类方法，拿到可信的对比表与失败案例，并确定 Phase 2 的方法切口。

---

## 1. 问题定义

成像模型：$y = A x + n$

- $x \in \mathbb{R}^{256\times256}$：归一化 CT 切片（HU 裁剪 [-1000, 1000] → [-1, 1]）
- $A$：平行束 Radon 变换（`src/physics/radon.py`，PyTorch 可微实现，支持任意角度子集）
- 稀疏视角：$N_\theta \in \{30, 60, 90\}$ 个角度（全采样 180 个）
- 低剂量：$N_\theta=180$，在投影域加 Poisson 噪声（入射光子 $I_0 \in \{10^4, 5\times10^4\}$）
- 限角（第 3 周加）：角度范围 [0°, 120°]

> 为什么先做仿真而不是真实投影：公开的真实投影数据（Mayo LDCT 投影域）需申请，且几何复杂。仿真数据让物理算子 $A$ 完全已知，适合先验证后验采样方法本身；算子失配留到 Phase 2 作为独立问题。

## 2. 数据

**TotalSegmentator v2.0.1**（Zenodo 10047292，23.6 GB，1228 例 CT，1.5 mm 各向同性）。

- 先用官方 102 例小子集（见 Zenodo 页面链接）跑通；再换全集。
- 预处理（`src/data/prepare_slices.py`）：读 `ct.nii.gz` → 取轴位切片 → 中心裁剪/缩放到 256² → HU 窗 [-1000, 1000] → 按 `meta.csv` 的 split 划分 → 写入 `slices_{train,val,test}.npy`（float16）。
- 每例抽取 ≤ 40 张含体部（前景占比 > 10%）的切片，训练集约 3–4 万张。
- 测试集固定 200 张切片（跨 20 个不同病人），所有方法共用，`seed=0`。

## 3. 方法矩阵

| # | 方法 | 类型 | 训练成本 | 代码 |
|---|---|---|---|---|
| B0 | FBP（Ram-Lak，`src/physics/radon.py::fbp`） | 解析 | 0 | 已实现 |
| B1 | FBPConvNet：FBP → U-Net 残差后处理，每种采样率单独训练 | 监督 | 2 h/设置 | `src/baselines/train_fbpconvnet.py` |
| M1 | 流匹配先验（无条件，`src/train_flow.py`）+ 测量引导采样（`src/sample_posterior.py --guidance dps`） | 生成式后验 | 先验训练一次 ~12 h（A100） | 已实现 |
| M2 | 同一先验 + ΠGDM 风格的伪逆引导（`--guidance pigdm`） | 生成式后验 | 0（复用先验） | 已实现 |
| M3 | 同一先验 + 数据一致性投影（每步后做共轭梯度 DC，`--guidance dc`） | 生成式后验 | 0 | 已实现 |

M1–M3 共用一个先验，差异只在采样期如何引入 $y$。这是本阶段最重要的对照：说明在流匹配 ODE 轨迹上，**哪种引入测量的方式**最稳。

## 4. 评价

- 像素指标：PSNR、SSIM（HU 域，窗 [-1000, 1000]）
- 感知指标：LPIPS（第 2 周加入）
- 数据一致性：$\|A\hat{x} - y\|_2 / \|y\|_2$
- 不确定性（仅生成式）：每张测试图采样 8 次，报告像素标准差图与 PSNR 的均值 ± 标准差
- 效率：NFE、单张耗时（A100）
- 失败案例：每个设置挑 PSNR 最低 5 张做可视化（`results/<exp>/failures.png`）

## 7. 风险与对策

- 先验训练不收敛 / 采样伪影：先用 128² 分辨率调通，再升 256²；检查 HU 窗与归一化一致。
- 生成式方法 PSNR 不如监督 U-Net：这是常见现象，报告 LPIPS/不确定性/泛化（跨采样率不重训）作为优势，不要为了 PSNR 调过拟合。
- Zenodo 下载慢：用页面提供的 Dropbox 镜像，或先用 102 例子集。
- AutoDL 无法 `npm install`：开启学术加速或用本地 Claude Code 通过 ssh 远程执行。

## 8. 方法点候选（W3 末决定一个）

1. **流匹配后验采样的步长/引导自适应**：以 $x_1$ 预测的测量残差为信号自适应 ζ，比较与 DPS 固定 ζ 的稳定性差异。
2. **盲反问题**：角度/中心偏移作为未知参数，与 $x$ 交替估计（EM 风格）。
3. **2.5D 体积一致**：2D 先验 + 相邻切片一致性正则，为 Phase 2 的 3D 扩展铺路。
