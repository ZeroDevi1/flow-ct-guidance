# Phase 1b 设计 · 角度序列 SSM 补全器 + HLCC + 限角外推（方案 A + 扩展 1 + 2）

**日期**：2026-10-19　**前置**：Phase 1 先验 `checkpoints/prior_256/ema_final.pt`（19.8M，12 万步），新颖性核查见 `docs/02_novelty_check.md`。
**目标**：在**冻结的**图像域流先验之上，把 M3 的数据一致性从"只在已测角度上拉回"推广到"在全角度网格上、按逐角度置信度加权拉回"。缺失角度由一个以 t 为条件、沿 θ 扫描的小 SSM 补全，并用 Helgason–Ludwig 一致性条件约束；同一个补全器覆盖稀疏视角（插值）和限角（外推）。

## 1. 记号与几何

- 全角度网格 Θ_full：180 个角度，[0, π) 内每 1° 一个。已测角度 Θ_m ⊂ Θ_full：
  - 稀疏视角 30/60/90：每隔 6°/3°/2° 取一个（与 `CTOperator(n_angles=k)` 的 `linspace(0, π, k+1)[:-1]` 一致）；
  - 限角：[0°, 120°) 和 [0°, 90°)，每 1° 一个（`angle_range=2π/3, n_angles=120` 等）。
- A_full：180 角的平行束算子；P_m：从全角度中取出已测的行；y = P_m A_full x + n。
- 周期延拓：s(θ+π, r) = s(θ, −r)，把 180 行延拓成 360 行的严格周期序列，供 SSM 的环形扫描和 HLCC 拟合使用。

## 2. 采样器：guidance = `dcfull`

在 M3 的每一步，即 x̂₁ = x_t + (1−t) v 之后：

1. s_pred = A_full(x̂₁)　　（180×256，当前干净估计的全角度正弦图）
2. (ŷ, log σ²_θ) = C_φ(s_pred, y 放到已测行, 掩码, t)；已测行强制 ŷ = y、权重 w = 1
3. （扩展 1，可开关）ŷ ← Π_HLCC(ŷ; w)：只修正未测行，使各阶矩满足 HLCC
4. x̂₁^dc = argmin_x ‖W^{1/2}(A_full x − ŷ)‖² + λ‖x − x̂₁‖²，W = diag(w_θ)，未测行 w_θ = κ·σ̄²/σ²_θ，用 CG 求解
5. x_{t+Δt} = (1 − t₊) ε̂ + t₊ x̂₁^dc　　（与 M3 相同的 DDNM 式重组）

λ 用相对量纲（同 M3），κ 在 val 上调。**不学习的对照**：
- `dcfull-interp`：ŷ 的未测行用已测行沿 θ 的环形线性插值，w = κ；
- `dcfull-pred`：ŷ 的未测行 = s_pred（等价于 M3 加了一个额外的近端项），用来确认增益来自补全器，而不是来自全角度算子本身。

## 3. 补全器 C_φ（`src/models/angle_ssm.py`，约 2M 参数）

- **输入**：[s_pred, y⊙m, m] 三个通道 × 360 行（延拓后）× 256 探测器单元，加上 t。
- **探测器编码**：1D 卷积沿 r 方向下采样到 64，每行展平后线性映射到 d=256。
- **角度混合器**（`mixer` 参数，用于消融）：
  - `ssm`：4 层双向选择性 SSM（Mamba 式：Δ、B、C 随输入变化，d_state=16）。环形处理方式是在两圈序列上扫描、取第二圈的输出。用纯 PyTorch 分块扫描实现，**不依赖 mamba-ssm**；
  - `conv`：沿 θ 的 1D 空洞卷积，层数相同、感受野相当；
  - `attn`：沿 θ 的自注意力，加环形相对位置编码。
- **t 条件**：用 FiLM 注入每一层（`t_cond=False` 用于消融）。
- **解码**：输出每行的残差 δs（256 维）和 log σ²_θ。ŷ = s_pred + δs。

## 4. 训练（`src/train_completer.py`）

- 先验冻结。对训练切片 x 采样 t ~ U(0.05, 1)、ε，令 x_t = (1−t)ε + t x，用 x̂₁ = x_t + (1−t) v_θ(x_t, t) 构造 s_pred，每个 batch 只需一次前向、不求梯度。
- 掩码随机混合：稀疏视角（20–120 视角，规则间隔、随机起始相位）占 60%，限角（60°–150° 范围、随机起点）占 40%。
- 测量 y 由真实切片 A_full x 取已测行得到；低剂量时加 Poisson 噪声。
- 损失 = 未测行上的异方差 NLL：mean[(ŷ − s_true)²/σ² + log σ²] + β·HLCC 残差（扩展 1 的训练损失形式）。
- 预算：batch 16，约 15k 步。5090 上预计约 2 小时（含先验前向），还没实测。

## 5. HLCC 投影（`src/physics/hlcc.py`）

- 探测器坐标归一化到 r ∈ [−1, 1]。n 阶矩 M_n(θ) = Σ_r s(θ, r) r^n，n = 0..N（N 默认 6）。
- 允许的谐波：|m| ≤ n 且 m ≡ n (mod 2)。在 360 行的周期延拓上做加权最小二乘拟合，得到 M̃_n。
- 修正：对每个未测行，求满足 Σ_r δ(θ, r) r^n = M̃_n(θ) − M_n(θ) 的最小范数 δ，即 δ = Rᵀ(RRᵀ)⁻¹ΔM，其中 R 是 (N+1)×256 的幂次矩阵（数值上用 Legendre 基代替幂次）。
- **单元测试**：真实 Radon 正弦图的 HLCC 残差应接近离散化误差；随机扰动后的正弦图投影后残差应下降。

## 6. 评测矩阵（固定 test200，按病人 bootstrap）

| 设置 | 方法 |
|---|---|
| sv30 / sv60 / sv90 | FBP、FBPConvNet、M2、M3、dcfull-interp、dcfull-pred、**dcfull（SSM）**、dcfull+HLCC |
| la120 / la90（新增） | FBP、M2、M3、dcfull-interp、**dcfull（SSM）**、dcfull+HLCC |

**消融**（sv60 + la120）：mixer ∈ {ssm, conv, attn}；t 条件开 / 关；置信度开 / 关（w 固定为 κ）；HLCC 开 / 关；跨视角数泛化（同一个补全器用于 30/60/90）。

## 7. 止损与预算

- **止损**：补全器训练约 4 GPU 小时后，若 sv60 上 dcfull 比 M3 提升 < 0.3 dB，或数据一致性变差，就停止，改回顾问报告中的方案 B 或 C。
- **预算**：约 8–10 GPU 小时，约 ¥23–29；剩余余额约 ¥70。
- **开机时机**：代码写完、在本地 CPU 上冒烟通过后再开 5090。
